# Extension PRP — Specialist portfolio capabilities

Status: backlog. These are future, separately requested lessons. They preserve the original ambition of a broad portfolio manager while the main course builds a coherent first system.

## Admission rule for every extension

Create a dedicated PRP using the template. Specify instrument cash flows, identity and market conventions, provider sufficiency, accounting events, valuation, risk, order lifecycle, settlement, performance and report impacts. A new instrument is not supported merely because Yahoo returns a price.

## Extension tracks

| Track                                  | Catalog             | Required additions and proof                                                                                                                 |
| -------------------------------------- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Direct bonds and credit                | D20–D21             | Accrued/clean/dirty price, day-count, coupon schedule, yields, curves, duration/convexity, spread/default risk and cash-flow reconciliation  |
| Options and derivatives                | D22                 | Contract multipliers, expiry/exercise/assignment, pricing assumptions, Greeks, margin/collateral and scenario P&L                            |
| Futures and commodities                | D23                 | Contract identity, roll policy, variation margin and expiry; separate continuous research series from actual held contracts                  |
| Multi-currency and hedging             | D24                 | Quote direction, valuation/cash FX, forwards, hedge rolls, translation attribution and settlement exposure                                   |
| Digital assets                         | D25                 | Custody/finality, oracle integrity, transaction fees, liquidity/liquidations, protocol-specific balances and risk                            |
| Sharia mandates                        | D26                 | Named screening methodology/version, ratio inputs, purification, review dates and auditable decisions                                        |
| Household and goal management          | D31/D33/D34         | Multiple accounts, liabilities/goals, cash planning, withdrawal simulations, asset location and jurisdiction-specific tax policies           |
| Factor and company intelligence        | D17–D19/D46–D48     | Historical filings, period normalization, earnings dilution, forecasting, valuation uncertainty and factor attribution                       |
| Intraday execution and TCA             | D01-F05/D11–D13/D43 | Licensed ticks/quotes, book reconstruction, routing, execution models, markouts, fill realism and broker/custodian adapters                  |
| News, alternative data and forecasting | D35–D38/D40–D41     | Availability, entity matching, data rights, statistical validation, drift, causal limits and evidence-grounded explanations                  |
| Advisory product operations            | D27–D29/D32/D44     | Add only for a defined lending, funding, fraud, insurance or billing requirement; these do not automatically follow from portfolio analytics |
| Enterprise operation                   | D30/D41–D45/D49     | Tenant/account isolation, approval duties, regulated reporting, record retention, security operations and tested recovery                    |

## Completion contract

An extension is complete only when its events reconcile into the existing book, valuations and risks use the correct instrument semantics, the UI shows unsupported states, independent cases pass, and reports disclose the method and coverage. Update the course map and capability matrix when implementation ships.

Do not turn a catalog title into an import or a regulatory claim without checking the release and applicable primary sources.
