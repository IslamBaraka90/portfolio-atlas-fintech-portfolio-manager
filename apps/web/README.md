# React and Vite portfolio management desk

The React app renders provider-neutral API results, uncertainty, validation reasons, and workflow states. It will never import yahoo-finance2 or recompute authoritative NAV and returns. Chapter 1 supplies the first runnable screen.

Chapter 1 is implemented: the React mandate lab creates portfolios, edits policy revisions and renders server allocation findings. It includes synthetic scenarios, accessible errors and desktop/mobile layouts. See the [learning guide](../../docs/chapters/01-learning-guide.md).
