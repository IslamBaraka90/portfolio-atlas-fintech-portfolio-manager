# Deterministic financial examples and future test helpers

Fixtures will be synthetic by default and independently auditable. Expected results must include derivations, rounding policy, event order, and as-of time. Live Yahoo requests belong to opt-in integration checks, never the default suite.

Chapter 1 provides deterministic synthetic mandates and allocation fixtures. Tests inject clocks and ID factories explicitly. The local lesson API serves these same public teaching inputs.
