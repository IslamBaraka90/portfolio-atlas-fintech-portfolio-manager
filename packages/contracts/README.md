# Provider-neutral API and event contracts

Chapter 1 supplies Zod schemas and inferred TypeScript types for mandates, candidate weights, portfolios, findings, evaluations and HTTP envelopes. Times use ISO UTC instants, weights use fractions, and currencies are explicit. Future monetary accounting contracts will add their own decimal representation.

Status: structure and dependencies only. No application implementation exists yet.
